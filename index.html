Credit Risk Modeling Explainable ML FinTech XGBoost

Credit Risk Assessment Engine

Lenders need more than a single default score - they need to know how much they'd actually lose, and on which loans, before capital is committed. This project turns raw LendingClub loan applications into a full expected-loss estimate in real time.

  • Built a three-model XGBoost pipeline - Probability of Default, Loss Given Default, and Exposure at Default - trained on 1.35M+ historical loans and combined into a single Expected Loss score (EL = PD × LGD × EAD), served through a FastAPI backend with a Streamlit UI for instant, form-based risk checks.
  • Calibrated raw PD outputs with isotonic regression so predicted probabilities actually match observed default rates, not just rank-order them - critical for a number that gets multiplied into a dollar figure.
  • Validated against a $19.4B loan portfolio, achieving a 0.73 AUC and EL rates that scale monotonically from 1.9% (Grade A) to 33.9% (Grade G) - matching real-world credit risk ordering.

GenAI Diffusion Models Image-to-Video Generation Hugging Face Spaces

Image/Text to Image/Video Generator

Creating a short animated clip normally means juggling separate tools for image generation and video synthesis, which is slow and hard for beginners to chain together.

  • Built a two-stage Gradio app on Hugging Face Spaces. Users enter a text prompt, with an optional reference image, to generate a 1024x576 image using FLUX.2 Klein 4B. They then add a motion prompt, and LTX-Video 0.9.8 distilled animates that image into a five-second, 24 fps clip.
  • A key decision was a two-pass video pipeline. It generates at two-thirds resolution, applies a 2x latent upscale, and refines using the checkpoint’s own timestep schedules. VAE tiling keeps memory in check. Models load on CPU at startup and move to GPU only inside ZeroGPU-decorated functions, then return to CPU afterward, so both large models share limited hardware.
  • The result is a working, publicly accessible demo that produces 121-frame videos from a single prompt, with the image step taking only four inference steps.
